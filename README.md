# Hostel & Mess Logistics System

A web-based Hostel & Mess Logistics System developed to simplify hostel operations and improve student services.

## Features

### Admin
- Admin Login
- Student Management
- Add Student
- Edit Student
- Delete Student
- Automatic Student Login Credentials
- Room Management
- Room Type Management
- Room Allocation
- Room Occupancy Tracking
- Maintenance Ticket Management
- Digital Gate Pass Management

### Student
- Student Login
- View Room Details
- Raise Maintenance Ticket
- Track Maintenance Ticket Status
- Request Digital Gate Pass
- Track Gate Pass Status

## Room Types

| Room Type | Capacity | Geyser |
|---|---:|---|
| Deluxe | 5 | Yes |
| Normal | 8 | No |
| AC | 4 | Yes |
| Big Room | 20 | No |

## Technology Used

- HTML
- CSS
- PHP
- MySQL
- XAMPP

## Main Modules

1. Room Allocation
2. Maintenance SLA Ticketing
3. Mess Demand Forecasting
4. Digital Gate Passes

## Project Purpose

The system is designed to manage hostel operations digitally, reduce manual work, and provide students with convenient access to hostel services.

## How to Run

1. Install XAMPP.
2. Copy the project into:

   `C:\xampp\htdocs\`

3. Start Apache and MySQL.
4. Create a database in phpMyAdmin.
5. Import `hostel_mess_system.sql`.
6. Update the database connection configuration.
7. Open:

   `http://localhost/HostelMessSystem/`
